# PORT BOT PRO — автономный тестовый симулятор

Это готовая программа с автономным агентом, который в изолированной тестовой сцене выполняет цикл:
поиск коробки → подход → подбор → доставка → мини-игра → повтор.

**Важно:** программа не подключается к GTA/RAGE MP, не внедряется в процессы и не отправляет команды в сторонние игры. Вся автономность реализована внутри собственного симулятора.

## Запуск в Windows
1. Установи Python 3.11 или новее.
2. Распакуй архив.
3. В папке проекта выполни `python port_bot.py`.

Никакие сторонние Python-пакеты не нужны.

## Сборка EXE через GitHub Actions
Загрузи содержимое папки в GitHub-репозиторий. Workflow запускается при push в `main`/`master` или вручную через Actions. Готовый EXE появится в Artifacts.
